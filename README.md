# Beyond the Lab

This repo contains:

1. **Data Management Plan (DMP):** An anonymised version describing data collection, storage, access, and ethical considerations.
2. **Participant background questionnaire:** Questions about participants’ professional roles, domains, and relevant experience.
3. **Codebook:** Codes and definitions used for qualitative analysis.
4. **Interview summary tables:** Findings organised by participant and code (anonymised).
5. **Interview guide:** Questions used in the semi-structured interviews.
